# villa-mep-check-scripts — سكربتات فحص MEP للقراءة فقط (C#)

> **الغرض:** بوابات فحص للقراءة فقط تُشغَّل على النموذج كاملًا قبل كل تسليم MEP وبعد كل مهمة كتابة (v2، معايَرة على WEDAD 2026-11-11، المنهج حتى 2026-11-15). **متى تُستخدم:** قبل أي تسليم أو مراجعة MEP في مشاريع فلل شريف على Revit: مسارات السباكة، مسارات التكييف، أجهزة الكهرباء.

## الفكرة الأساسية
خيط drafting يشغّل الفحوص قبل التسليم، و revit review يعيد تشغيلها بنفسه ولا يثق في TSV الرسّام. كود v2 (~70 KB) ليس داخل الـ skill: النسخة الأم في WEDAD `claude\qa\scripts\` (لا تُعدَّل من مشروع آخر)، ويرفقها شريف لكل مشروع في `claude\qa\scripts\`. كود v1 متقاعد ولا يُشغَّل.

### تفاصيل الفحوص (v2)
**السباكة** (مواسير ≥ 0.15 m؛ أنظمة REFRIG, RL, RG, CD, CONDENS مُتخطاة لأنها للتكييف)
- **C1 NOT_IN_WALL:** < 90 % من المحور داخل solids جدران البلوك. يُتخطى بأي place code، أو داخل صندوق shaft، أو ذيل قطعة ≤ 0.35 m ينتهي في جدار بلوك.
- **C2 NEAR_GLAZING:** مسافة SOLID ≤ 0.30 m من الزجاج (نوافذ؛ أبواب/curtain panels أسماؤها GLASS, GLAZ, SGD؛ ليس ACCESS, SLAT, FAC؛ بلا curtain walls وبلا swing boxes). لا يُختبر لـ I/W، SH، U/G، shaft، أو نسبة بلوك ≥ 90 %؛ SUS يُتخطى فقط إذا كان رأس الفتحة عند/تحت أسفل السقف.
- **C3 DRAIN_OVER_ROOM:** waste/soil/rain (لا التكثيف) فوق غرف اسمها BEDROOM, MASTER, CHILDREN, MAID ROOM, DRIVER ROOM, LIVING, FAMILY, SEATING, MAJLIS, HALL, DINING؛ OUTDOOR مستثنى.
- **C4 LOW_SLOPE:** صرف < 1 % عند ≥ 100 mm، و < 2 % لما دونه (أو أساس تصميم المشروع).
- **C5:** connectors مفتوحة على مواسير/قطع/ملحقات السباكة؛ **C5F:** طرف مفتوح خلال 50 mm من قطعة بلا connector.
- **C6:** قطعة بلا صرف و/أو بلا تغذية (بالـ connectors، وإلا بالموضع خلال 50 mm)؛ قطع الصرف فقط لا تُختبر للتغذية.
- **C7:** رأس صاعد/vent مفتوح أو ميت عند/فوق السطح أو بلا بلاطة فوقه؛ التكثيف مستثنى؛ يُقبل كنهاية: CAP, VENT, TERMINAL, COWL, ROD, AAV, FLOOR DRAIN, DRAIN, PLUG.

**التكييف** (كل الدكت + مواسير الفريون/التكثيف)
- **H1:** مرور أفقي عبر، أو طولي داخل، solid كمرة/عصب/عمود (المضيف أو رابط)، > 0.02 m داخلها؛ نسخة المضيف + توأم الرابط = إصابة واحدة. يُختبر لكل منحنى أيًا كان كوده.
- **H1B:** مرور رأسي عبر كمرة ليست عصبًا؛ عبر عصب أو بلاطة فقط = عدّ معلوماتي.
- **H2:** دكت يتقاطع مع سقف. **H3:** connectors مفتوحة HVAC/فريون/تكثيف (connectors المياه/vent/الحريق والكهرباء في المعدات تُتجاهل؛ الخزانات والمضخات لا تُختبر). **H4:** ODU ليس على منسوب سطح.
- **H5:** فريون/تكثيف خارج فراغ السقف أو الجدار أو الـ shaft (ليس SUS / I/W / SH). داخل فراغ السقف المستعار ليس مخالفة؛ H5 وحده يُزال بـ place code.

**الكهرباء**
- **E1:** جهاز داخل solid عمود أو ≤ 50 mm من وجهه (مضيف أو رابط؛ التوأم مرة واحدة). **E2:** مقبس/مفتاح في جهة فتح الباب (يُتحقق منه). **E3A:** مقبس/مفتاح/وحدة إنارة بلا دائرة. **E3B:** جهاز تيار خفيف بلا نظام من نوعه. **E4:** دائرة قوى ≤ 0 VA. **E5:** غرفة نوم بلا كاشف دخان (فقط إن كان الإنذار ضمن النطاق). **USED:** أنواع العائلات للمقارنة مع الـ legend.

### قاعدة الكمرات في كل فحص إنشائي (2026-11-12؛ حدود الرسم 2026-11-14)
- ماسورة رأسية تمامًا (خلال 1°) عبر كمرة/عصب/بلاطة مسموحة: تُطبع `B-VERT-OK` ولا تُعَد ولا قائمة PENDING.
- يُعَد فقط: `B-LEN` (طولي في كمرة: المحور خلال 30° من محور العضو وأفقي، أو أكثر من عمق العضو + 0.05 داخله)، `B-NONVERT` (عبور بانحراف > 1° عن الرأسي)، قطعة داخل عمق البلاطة/الكمرة، وأي شيء في/على عمود أو في جدار خرساني.
- حدود التصميم الجديد (OD ≤ b/3، cover ≥ 7 cm، لا قطعة داخلها، المحور ≥ 0.15 من كل وجه) تُفحص على الورق؛ في النموذج الأعلام القديمة (B-OD110 / B-20 / B-SUPPORT / B-EDGE / B-CLUSTER) أعمدة معلومات فقط لا تضاف إلى TOTAL.
- تجاوز الحد لا ينقل الصاعد خارج الجدار: يبقى ويُكتب في قائمة المهندس الإنشائي؛ نقل الصاعد خارج/بجانب الجدار أو إلى chase/box = عيب (2026-11-25). قاعدة RISERS FULLY INSIDE WALLS لكل التخصصات.

### أكواد الموضع (Place codes)
في Comments للماسورة (كلمة كاملة) أو ملف `qa\CALIB_place_codes.tsv` (id, system, family, code, evidence). أول تطابق يفوز: I/W > SH > U/G > T/B > SUS > U/S. `SUS?` و `U/S?` ليست أكوادًا.

| الكود | القاعدة الهندسية |
|---|---|
| I/W | ≥ 90 % من المحور داخل solid جدار بلوك |
| SH | نقطة المنتصف في صندوق Shaft Opening أو light-well مُعلن |
| U/G | > 50 % في ردم البدروم، أو خارج المسقط تحت المنسوب ومغطى (شعاع لأعلى من الطرفين والمنتصف يصيب أرضية/رصف/بلاطة/قاعدة خلال 3 m). الفناء المفتوح = NONE |
| T/B | المرور الرأسي نفسه: > 50 % من المحور داخل بلاطة/عصب/كمرة/قاعدة (صاعد في غرفة = NONE) |
| SUS | الطرفان والمنتصف فوق سقف مغلق (شعاع لأسفل يصيب سقفًا قبل أرضية) |
| U/S | تحت بلاطة بلا سقف، في غرفة معدات فقط |
| NONE | غير ذلك، بما فيه داخل عمق البلاطة أو طبقات الأرضية: REAL |

- Title guard `"00004-KHL-WBA"` → كود ملف المشروع.
- مجلد الإخراج `D:\Projects\...\claude\qa\` → `claude\qa\` للمشروع.
- فصل الوحدات `A if x < 13.00` (C5/C6/C7) → محور مرآة المشروع أو حذفه.
- إحداثيات light-well المعدودة SH (HVAC A) → الآبار/الـ shafts الفعلية.
- عناصر ردم البدروم (U/G) → عناصر المشروع.
- اسم منسوب السطح `04-ROOF` (C7) ونوع العصب `15X33` (H1B) → أسماء المشروع.
- كلمات الغرف/الأنظمة (C3, E5, REFRIG/RL/RG/CD/CONDENS) → مطابقة للأسماء الحقيقية.

### النماذج متعددة الملفات
- v2 يقرأ الإنشاء (كمرات، أعصاب، أعمدة، بلاطات، قواعد) من المضيف وكل رابط بـ `li.GetTotalTransform()`.
- يقرأ المعماري (جدران، نوافذ/أبواب، curtain panels، غرف، أسقف، shaft openings) من المضيف فقط. إن كان المعماري رابطًا فإن C1، C2، C3، C6 (POS)، H2، H5، E2، E5 وأكواد الموضع لا تجد شيئًا بصمت.
- الحل: توسيع المجمّعات لمستند الرابط المعماري وتحويل كل solid (`SolidUtils.CreateTransformed`) ونقطة (`tr.OfPoint`)، والغرف بـ `tr.Inverse.OfPoint(p)`. اختيار الروابط بالاسم. طباعة سطر عدّ المصادر؛ 0 = تشغيل فاشل. ملف MEP واحد لكل تشغيل.

### قواعد Revit 2026 / الجسر
- C# 5 فقط: لا `$""` ولا `?.` ولا `is T x`. الجسم ينتهي بـ `} static void Dummy(){` لتترجم الفئات المساعدة.
- `ElementId.Value` و `Category.Id.Value` بدل IntegerValue.
- كل مهمة < 7.5 KB بدون التعليقات (تقسيم A/B) أو عبر المحمّل.
- `if (!document.Title.Contains("<project code>")) return "WRONG DOC";`.

## خطوات العمل (Workflow)
1. اقرأ الدور من PM؛ اقفل فقط إن بدأ بـ FREE؛ Reload Latest وأعد تحميل الروابط.
2. كل فحص **Idling job**: يشترك في `UIApplication.Idling` ويلغي الاشتراك أول نداء ويكتب TSV. بلا Transaction، بلا كتابة Comments، بلا إخفاء أو تغيير منظر أو sync؛ لا say_hello.
3. أرسل المهمة مباشرة (< 7.5 KB) أو عبر المحمّل (للقراءة: SV = عدد الحفظ الحالي، LOG اسم جديد لكل تشغيل).
4. عند timeout لنداء MCP: انتظر ملف الإخراج، لا تعِد الإرسال.
5. النموذج كاملًا فقط؛ pilot على منسوب للتصحيح فقط.
6. أبلغ `saves N GUID` مع عدد العناصر والتحذيرات.
7. الترتيب: (أكواد الموضع عند المعايرة) → PLB A, B, C5, C6, C7 → HVAC A, B → ELEC A, B؛ WS_AFTER_TURN_CHECK بعد كل كتابة.
8. اقفل FREE وأضف سطرًا في `coord\REVIT_TURN_LOG.md`.

**المعايرة (أول استخدام أو بعد تغييرات كبيرة):**
1. revit review يشغّل AUDIT للقراءة (KEEP / FIX / REDO مع ids) وكل الفحوص.
2. عينة عشوائية بـ seed ثابت 20 صفًا لكل فئة (C1, C2, C3, H1, H3, E1, E3).
3. كل صف يُحكم من solids/أشعة حية: REAL أو SCRIPT مع سبب.
4. أكواد الموضع من الهندسة إلى ملف override أولًا، ثم كتابة Comments بمهمة كتابة، وإعادة الفحص للتأكد من تساوي الأعداد.
5. تغييرات دنيا بأسماء جديدة؛ تشغيل 2 = FINAL؛ تحديث الـ skill. (WEDAD: سباكة 2497 → 874؛ تكييف 336 → 861 لأن 455 ماسورة فريون/تكثيف كانت غير مرئية.)

## أخطاء ممنوعة / تحذيرات
