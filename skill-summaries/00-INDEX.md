## ملاحظة عن الإنشائي (Structure)
لا يوجد skill مخصص للتصميم الإنشائي. الجوانب الإنشائية موجودة فقط ضمن: التنسيق (revit-clash-coordination)، المناسيب وطبقات السطح (villa-levels-regulations)، وقواعد الموديلنج في bim-revit-engineering وsenior-architect-revit-practice.

## مهارات الـ Plugin في هذا الـ repo (`skills/`)
بالإضافة لما سبق، الـ repo فيه 25 skill عامة لـ Revit/Dynamo/ACC (ملفاتها الأصلية مختصرة أصلاً):
| Skill | الوظيفة |
|---|---|
| generate-dynamo / export-dynamo-file | سكريبت Dynamo Python جاهز / ملف .dyn |
| revit-api-code | كود Revit API بـ C# أو Python (macros, add-ins, pyRevit) |
| query-model / manipulate-elements | استعلام وتعديل العناصر |
| manage-parameters / shared-parameters / validate-parameters | البارامترات: تعديل، shared، فحص اكتمال (BEP) |
| batch-rename-elements | إعادة تسمية جماعية |
| create-schedule / export-to-excel | جداول وكميات وتصدير CSV/Excel |
| manage-sheets / create-view-filters | اللوحات والـ views والفلاتر |
| analyze-rooms | الغرف والمساحات GIA |
| audit-model / linked-model-check / workset-manager | صحة الموديل والروابط والـ worksets |
| clash-detection | كشف التعارضات بـ Dynamo |
| export-ifc | تصدير IFC 2x3 / IFC4 |
| project-setup | إعداد المشروع: levels, grids, templates من BEP |
| acc-api-setup / acc-docs / acc-coordinate / acc-design-collaboration / acc-reports | Autodesk Construction Cloud |
