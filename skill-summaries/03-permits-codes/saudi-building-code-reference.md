# saudi-building-code-reference — مرجع كود البناء السعودي

> **الغرض:** البحث عن متطلبات كود البناء السعودي (SBC) والاشتراطات البلدية في مكتبة شريف على Google Drive والاستشهاد بالكود والبند. **متى تُستخدم:** عندما يحتاج أي مشروع متطلبًا من SBC أو اشتراطًا بلديًا سعوديًا.

## الفكرة الأساسية
المرجع الدائم لأسئلة الكود في كل مشاريع شريف (فلل، أبراج، أي تخصص). قبل الإجابة من الذاكرة: افتح ملف الـ PDF المناسب عبر Google Drive connector (`read_file_content` / `download_file_content` بالـ file ID) واقتبس رقم الكود والبند. إن لم يكن الـ connector متصلًا اعرض توصيله.

- لا تنزّل الملفات الضخمة (> 50 MB) إلا عند الحاجة.
- الرد لشريف بالعربية.

1. حدّد الكود المناسب من الجدول (للفلل ابدأ بـ 1101/1102).
2. افتح الملف عبر Google Drive connector بالـ file ID (اعرض التوصيل إن لم يكن متصلًا).
3. ابحث عن البند واقتبسه بصيغة "SBC <no> section <x>".
4. نبّه إلى احتمال وجود إصدار أحدث حيث ينطبق.
5. إن توقف file ID: اسرد المجلد مجددًا (search parentId = '1e3V8i3wQrhl9tqbhZ6JMWgaW1gEH0KMS') وحدّث الـ skill.
